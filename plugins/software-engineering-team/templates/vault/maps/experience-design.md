# Experience Design

One canonical acceptance application and its living process-owned Experience
packages. The application lives at
`../experience-design/artifacts/application.html`; each package maps exact
record revisions to its declared route/state entries through its version-2
`artifacts/application-map.json`. The root inline contract exposes the
complete deterministic state/outcome prototype. The experience-design entry
changes the application or package set only after the complete scope proposal
is approved.

No Experience application or package yet. The experience-design entry adds the
application link and primary BA process hubs when the first transaction is
approved.
