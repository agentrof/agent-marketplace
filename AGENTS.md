# Agent Marketplace source

This repository is the source of the Agent Marketplace. It is Claude
Code native; Cursor and Codex CLI install from the same tree through
generated manifests. This file is the contributor context for harnesses
that read AGENTS.md; Claude Code reads [CLAUDE.md](CLAUDE.md).

## Working in this repo

- Read [docs/architecture.md](docs/architecture.md) for the invariants
  and [docs/authoring.md](docs/authoring.md) before touching plugin
  content. Per-harness support lives in
  [docs/harnesses.md](docs/harnesses.md).
- Run `make check` before committing; CI runs the same gates and one
  finding is red.
- The source of truth is the tree under plugins/. Everything the other
  harnesses install (the .cursor-plugin and .agents registries, the
  per-plugin cursor/ and codex/ trees, skill policy files,
  templates/AGENTS.md, the runtime data file and the docs matrix block)
  is GENERATED by `make generate` from tools/data/harnesses.json.
  Generated files are never hand-edited; `make generate-check` fails CI
  on drift.
- Derived counts are never hand-written; `make counts` maintains the
  README marker block.
- Create new components with tools/scaffold.py, never by hand-copying;
  it registers the plugin and regenerates the harness artifacts itself.
- A release bumps the plugin version, its marketplace entry and runs
  `make generate` in one commit.
