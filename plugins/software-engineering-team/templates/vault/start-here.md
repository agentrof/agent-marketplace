# Start Here

- Open workspace/docs/ as the vault root, never the repository root:
  the graph boundary is exactly this tree.
- Committed app state: app.json, appearance.json, core-plugins.json,
  community-plugins.json, graph.json, types.json, plugins/ and
  snippets/ are managed by the team's setup and checks.
  workspace.json, workspace-mobile.json and .trash/ are your local
  state and stay untracked.
- Graph color legend: one color per document type (rules, decisions,
  acceptance, processes, entities), one for navigation notes, one for
  the delivery views. The GLOBAL graph filters out _generated views;
  the local graph keeps its own per-pane settings. Orphan and
  unresolved nodes are shown deliberately: they are defects, not
  decoration.
- Files whose first line reads "generated by ... do not edit by hand"
  are rendered views; edit the authored sources instead and the owning
  process re-renders them.
- The daily tool is the local graph (depth 1-2) on the note you are
  reading; the global graph is the onboarding and audit view.
