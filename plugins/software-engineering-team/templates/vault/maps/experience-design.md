# Experience Design

workspace at `../experience-design/artifacts/`. The prototype can use any
folders, files and technologies. The Experience entry snapshots its bytes and
paths with the process receipt set only after the complete scope proposal is
approved.

application link and primary BA process hubs when the first transaction is
approved.
