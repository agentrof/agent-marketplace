# Support

Use the repository's issue forms for reproducible defects, improvement ideas
and workflow questions. Include the host, package version, project setup and
the smallest safe reproduction needed to investigate.

Read the [authoring guide](docs/authoring.md) and
[Requirement and Delivery protocol](docs/requirement-delivery-protocol.md)
before opening a workflow question. Do not include credentials, private
project content or security-sensitive details in a public issue. Use
[SECURITY.md](SECURITY.md) for vulnerability reporting.
