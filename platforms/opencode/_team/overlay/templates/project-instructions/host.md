## OpenCode host

- Use the generated `.opencode` project projection and this team's namespaced
  commands, skills, and agents.
- Ask declared project decisions in normal conversation text with numbered
  options, recommendation, and tradeoffs. Native question UI is optional.
- Run state-changing work only after the user answers the declared decision.
- `opencode run` is limited to explicitly choice-free entries. Use the TUI for
  any workflow that needs user interaction.
